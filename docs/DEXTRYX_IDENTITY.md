# Dextryx Images product identity

The repository and Dart package keep their existing internal names. The shipped product identity is:

- Product / brand name: `Dextryx Images`
- Compact app label: `Dxtr Imgs`
- Master brand: `Dextryx`
- Android application ID / namespace: `com.cnxdev.dextryx.images`
- iOS bundle ID: `com.cnxdev.dextryx.images`
- macOS bundle ID: `com.cnxdev.dextryx.images`
- Linux application ID: `com.cnxdev.dextryx.images`

Platform test targets use the corresponding `com.cnxdev.dextryx.images.RunnerTests` identifier where applicable.

## Naming rules

Use `Dextryx Images` in title bars, About/metadata, installer/store-facing product identity, documentation, and other full product-name contexts.

Use `Dxtr Imgs` only where a compact launcher/app label is preferable.

Do not rename the GitHub repository as part of this identity change. The repository remains `dexter-cnx/nixin`, and internal Dart/package names may remain unchanged until a separate low-risk migration is justified.

The final decision and implementation checklist are recorded in `docs/DEXTRYX_IMAGES_HANDOFF.md`.
