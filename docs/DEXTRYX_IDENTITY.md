# Dextryx product identity

The repository and Dart package keep their existing internal names. The shipped product identity is:

- App name: `Dextryx`
- Android application ID / namespace: `com.cnxdev.dextryx`
- iOS bundle ID: `com.cnxdev.dextryx`
- macOS bundle ID: `com.cnxdev.dextryx`
- Linux application ID: `com.cnxdev.dextryx`

Platform test targets use the corresponding `com.cnxdev.dextryx.RunnerTests` identifier where applicable.
